# Pariwesh Tamrakar — Portfolio

My personal portfolio. Dark-themed, scroll-driven, built for craft.

![Portfolio preview](./public/preview.webp)

---

## Stack

Next.js 16 · React 19 · Motion · Tailwind CSS v4 · TypeScript · Vercel

## Run

```bash
npm install
npm run dev   # localhost:3000
npm run build
```

## Notes

- Import animations from `motion/react`, not `framer-motion`
- Tailwind v4 — no config file, uses `@theme {}` in `globals.css`
- Project data lives in `src/data/projects.ts`
- Canvas hero: 48 frames in `public/sequence/`
